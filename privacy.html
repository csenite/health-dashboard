Health Dashboard privacy policy

This is a personal dashboard used by one person, the owner of this site, to view their own health data.

  • It reads the owner's own data from the Google Health API and the owner's Google Drive, using access the owner granted.
  • The data is encrypted (AES-GCM) before it is stored in this site's repository, and can only be read with the owner's password.
  • No data is sold, shared with third parties, used for advertising, or collected from anyone else.
  • The owner can revoke access at any time from their Google Account permissions page.
